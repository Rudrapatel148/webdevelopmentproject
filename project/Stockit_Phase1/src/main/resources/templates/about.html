About Stockit

Stockit is a lightweight inventory management application for small teams that need a reliable product catalog.

It stores product SKUs, categories, quantities, prices, suppliers and reorder thresholds. Records are saved to a database and can be explored through a responsive browser interface.

Project scope

This Phase 1 implementation focuses on browsing, adding, filtering and sorting products. User authentication, editing and deletion are planned for later deliverables.
